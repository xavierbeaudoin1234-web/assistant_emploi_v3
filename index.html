Notes d'automatisation (GitHub Actions)

GitHub Pages est statique : pour exécuter des recherches automatiques, utilisez un workflow GitHub Actions (fichier .github/workflows/fetch_jobs.yml) qui :

  • récupère des flux RSS autorisés (Google Alerts si secret JOB_ALERT_FEEDS existe),
  • scrape des pages autorisées ou utilise des APIs publiques gratuites,
  • ajoute les nouvelles offres à jobs.json dans le repo (commit automatique),
  • fait attention aux règles d'usage et au CORS ; évitez le scraping de sites qui l'interdisent.
Exemple minimal de workflow (à placer dans .github/workflows/fetch_jobs.yml) : 
name: fetch-jobs
on:
  schedule:
    - cron: '0 */4 * * *' # toutes les 4 heures
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Fetch RSS feeds and update jobs.json
        env:
          JOB_ALERT_FEEDS: ${{ secrets.JOB_ALERT_FEEDS }}
        run: |
          # script shell/python/node pour récupérer des flux RSS et mettre à jour jobs.json
          echo "Add your feed fetcher here; do NOT commit secrets in code."

Je fournis ce workflow comme exemple ; si vous voulez, je peux fournir un script Node.js/Python prêt à coller dans le workflow pour récupérer des flux RSS et générer jobs.json à partir du secret JOB_ALERT_FEEDS sans modifier vos secrets.
